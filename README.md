# Голосовой AI-продажник

Полноценное web-приложение для голосовых продаж через AI. Пользователь сохраняет API-ключ ElevenLabs, создаёт AI-агента и ведёт голосовые разговоры в режиме реального времени.

## Что делает проект

- **Безопасное хранение ключа**: API-ключ ElevenLabs хранится только на сервере, никогда не передаётся в браузер
- **Создание AI-агента**: один клик — и на ElevenLabs создаётся настроенный AI-продажник с голосом и промптом
- **Голосовые звонки в реальном времени**: WebSocket + Web Audio API, стриминг аудио в обе стороны
- **Панель логов**: все события с временными метками видны в интерфейсе

## Установка зависимостей

```bash
pnpm install
```

## Запуск

Через Replit: workflow запускается автоматически.

Вручную:
```bash
# API-сервер
pnpm --filter @workspace/api-server run dev

# Frontend (в отдельном терминале)
pnpm --filter @workspace/voice-agent run dev
```

## Настройка API-ключа

1. Откройте приложение в браузере
2. Нажмите кнопку "⚙️ Настройки"
3. Введите API-ключ ElevenLabs (получить на https://elevenlabs.io)
4. Нажмите "Сохранить"

API-ключ хранится в файле `.data/settings.json` на сервере. В клиентский код не передаётся.

## Создание агента

1. После сохранения API-ключа нажмите "Создать AI-агента"
2. Агент создаётся на ElevenLabs с конфигурацией продажника CRM-системы
3. `agent_id` сохраняется в `.data/agent.json` и переиспользуется при следующих запусках

## Голосовой звонок

1. Нажмите "Позвонить"
2. Разрешите доступ к микрофону в браузере
3. Говорите — AI-агент отвечает голосом в реальном времени
4. Нажмите "Завершить разговор" для завершения

## Смена продукта

Откройте файл `artifacts/api-server/src/services/productConfig.ts` и измените объект `demoProduct`:

```typescript
export const demoProduct: ProductConfig = {
  name: "Ваш продукт",
  targetAudience: "целевая аудитория",
  painPoints: ["боль 1", "боль 2"],
  benefits: ["преимущество 1", "преимущество 2"],
  callToAction: "целевое действие",
};
```

Затем пересоздайте агента через интерфейс.

## Архитектура безопасности

- API-ключ **никогда** не попадает в frontend
- Все запросы к ElevenLabs идут через backend как прокси
- `/api/settings/status` возвращает только флаг `keySaved` и частично замаскированный ключ (первые 4 и последние 4 символа)
- Ключ не логируется на сервере

## Хранение данных

| Что | Где |
|-----|-----|
| API-ключ ElevenLabs | `.data/settings.json` (только на сервере) |
| `agent_id` | `.data/agent.json` (только на сервере) |

## Ограничения MVP

- Один агент на приложение (при создании нового агент заменяется)
- Нет поддержки нескольких пользователей
- Нет истории разговоров в базе данных
- Голосовой движок: ElevenLabs Conversational AI (требует активный аккаунт)

## API-эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/settings/save-key` | Сохранить API-ключ |
| GET | `/api/settings/status` | Статус ключа |
| POST | `/api/agent/create` | Создать AI-агента |
| GET | `/api/agent/status` | Статус агента |
| GET | `/api/conversation/signed-url` | Получить signed URL для WebSocket |
| POST | `/api/logs/client-event` | Логировать клиентское событие |
