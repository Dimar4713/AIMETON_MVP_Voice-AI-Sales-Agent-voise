# Voice AI Sales Agent

Русскоязычное web-приложение для голосовых продаж через ElevenLabs Conversational AI.
Приложение создаёт отдельных AI-агентов для онлайн-курса, фитнес-абонемента и CRM-системы,
а затем проводит двусторонние голосовые разговоры в браузере.

## Возможности

- API-ключ ElevenLabs хранится только на сервере и не передаётся в браузер.
- Создание и обновление независимого агента для каждого направления продаж.
- Загрузка текстового описания услуги (`txt`, `md`, `csv`, `json`, `html`, `htm`).
- Проверка микрофона, передача PCM16-аудио и воспроизведение ответа агента.
- Журнал событий, распознанной речи пользователя и ответов агента.

## Требования

- Node.js 20 или новее
- pnpm 9 или новее
- API-ключ ElevenLabs с доступом к Conversational AI

## Установка

```bash
pnpm install
```

## Запуск локально

Запустите API и веб-интерфейс в двух терминалах:

```bash
# API-сервер: http://localhost:5000
pnpm run dev:api
```

```bash
# Веб-интерфейс: http://localhost:5173
pnpm run dev:web
```

Vite проксирует запросы `/api` на API-сервер. Порты можно изменить:

```bash
PORT=5174 API_PORT=5001 pnpm run dev:web
PORT=5001 pnpm run dev:api
```

## Первоначальная настройка

1. Откройте `http://localhost:5173`.
2. Откройте настройки и сохраните API-ключ ElevenLabs.
3. Выберите направление продаж.
4. При необходимости загрузите описание услуги.
5. Создайте агента и разрешите браузеру доступ к микрофону.
6. Нажмите кнопку звонка и начните разговор.

## Хранение данных

Сервер сохраняет локальные данные в `artifacts/api-server/.data/`:

| Данные | Файл |
|---|---|
| API-ключ ElevenLabs | `.data/settings.json` |
| ID и конфигурации агентов | `.data/agent.json` |

Эта папка исключена из Git, поэтому ключи и рабочие ID не публикуются в репозитории.

## Проверка и сборка

```bash
pnpm run typecheck
pnpm run build
```

## Архитектура

- `artifacts/voice-agent` — React + Vite интерфейс.
- `artifacts/api-server` — Express API и прокси к ElevenLabs.
- `lib/api-spec` — OpenAPI-контракт.
- `lib/api-client-react` и `lib/api-zod` — сгенерированные API-клиент и схемы.

## Ограничения MVP

- Нет поддержки нескольких пользователей и авторизации.
- История разговоров пока не сохраняется в базе данных.
- Для работы нужен активный аккаунт ElevenLabs с доступом к Conversational AI.

## API-эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/settings/save-key` | Сохранить API-ключ |
| GET | `/api/settings/status` | Получить статус ключа |
| POST | `/api/agent/create` | Создать агента |
| GET | `/api/agent/status` | Получить конфигурации агентов |
| PATCH | `/api/agent/configuration` | Обновить конфигурацию агента |
| GET | `/api/conversation/signed-url` | Получить signed URL для WebSocket |
| POST | `/api/logs/client-event` | Записать клиентское событие |
