# TESTING.md — Тест-кейсы для голосового AI-продажника

## Предварительные условия для всех тестов

1. Приложение запущено (оба сервиса: API-сервер и frontend)
2. Получен валидный API-ключ ElevenLabs
3. Браузер поддерживает WebRTC / getUserMedia (Chrome, Firefox, Edge)
4. Доступен микрофон

---

## Тест 1: Продажа онлайн-курса

### Предусловия
- Изменить `demoProduct` в `productConfig.ts`:
  ```typescript
  {
    name: "Онлайн-курс по Python для начинающих",
    targetAudience: "студенты и начинающие специалисты",
    painPoints: ["не знаю с чего начать", "нет времени на очные курсы", "дорогие курсы"],
    benefits: ["формат видео + практика", "обучение в своём темпе", "доступная цена", "сертификат"],
    callToAction: "записаться на бесплатный вводный урок",
  }
  ```
- Пересоздать агента через интерфейс

### Шаги
1. Открыть приложение, убедиться: API-ключ сохранён, агент создан
2. Нажать "Позвонить"
3. Разрешить доступ к микрофону
4. Поприветствовать агента
5. Ответить на вопросы агента о своём опыте в программировании
6. Спросить: "Сколько времени в неделю потребуется?"
7. Уточнить стоимость курса
8. Сказать: "Хочу попробовать бесплатный урок"
9. Нажать "Завершить разговор"

### Ожидаемый результат
- Агент начинает разговор дружелюбным приветствием
- Задаёт уточняющие вопросы о текущем уровне знаний
- Отвечает на вопрос о времени: рассказывает о гибком формате
- На вопрос о стоимости называет преимущества формата
- После выражения интереса предлагает записаться на бесплатный урок
- При нажатии "Завершить разговор": WebSocket закрывается, микрофон освобождается, в логах появляется "разговор завершён"

## Тест 2: Продажа фитнес-абонемента

### Предусловия
- Изменить `demoProduct`:
  ```typescript
  {
    name: "Фитнес-абонемент клуба FitPro",
    targetAudience: "люди 25–45 лет, ведущие активный образ жизни",
    painPoints: ["нет времени ходить в зал", "дорогие залы рядом с домом", "теряю мотивацию один"],
    benefits: ["круглосуточный доступ", "персональные тренировки", "онлайн-план питания", "заморозка абонемента"],
    callToAction: "приехать на бесплатную первую тренировку",
  }
  ```
- Пересоздать агента

### Шаги
1. Начать разговор ("Позвонить")
2. Ответить, что хочете похудеть и укрепить здоровье
3. Сказать, что раньше пробовали ходить в зал, но бросили
4. Спросить: "Что если я куплю абонемент и опять не буду ходить?"
5. Сказать: "Мне далеко до вашего клуба"
6. Ответить на вопрос о бюджете: "До 5000 рублей в месяц"
7. Нажать "Завершить разговор"

### Ожидаемый результат
- Агент выявляет цель (похудение/здоровье)
- На вопрос о мотивации отвечает про персональные тренировки и систему поддержки
- Возражение про расстояние обрабатывает (онлайн-тренировки или несколько локаций)
- При бюджете 5000р предлагает подходящий тариф или специальное предложение
- Мягко предлагает бесплатную первую тренировку
- Завершение разговора: ресурсы освобождены корректно

## Тест 3: Продажа CRM-системы (дефолтный продукт)

### Предусловия
- `demoProduct` используется по умолчанию (CRM для малого бизнеса)
- Агент создан с дефолтной конфигурацией

### Шаги
1. Начать разговор
2. Представиться владельцем небольшого розничного магазина с 3 менеджерами
3. Ответить, что используете таблицы Excel для учёта клиентов
4. Пожаловаться, что "менеджеры забывают перезванивать клиентам"
5. Спросить: "А сложно ли это внедрить?"
6. Спросить про стоимость
7. Сказать: "Нам это подходит, хотим посмотреть подробнее"
8. Нажать "Завершить разговор"

### Ожидаемый результат
- Агент начинает с выявления текущей ситуации
- После жалобы на забытые звонки предлагает автоматизацию задач и напоминаний
- На вопрос о внедрении успокаивает, говорит о поддержке
- Предлагает целевое действие — демо-консультацию
- После согласия — фиксирует договорённость, вежливо завершает диалог
- Нажатие "Завершить" корректно останавливает всё

## Проверка технических характеристик

### Подключение к ElevenLabs
- [ ] Приложение успешно запрашивает signed URL у `/api/conversation/signed-url`
- [ ] WebSocket соединение устанавливается без ошибок
- [ ] В логах появляется "разговор начат"

### Голос в реальном времени
- [ ] Агент говорит голосом (не текст-to-speech с задержкой)
- [ ] Задержка ответа агента — не более 2-3 секунд
- [ ] Аудио-чанки воспроизводятся без перебоев и наложений

### Качество диалога
- [ ] Диалог выглядит естественно
- [ ] Агент задаёт уточняющие вопросы
- [ ] Агент не перебивает клиента (interruption handling работает)
- [ ] Ответы агента корректно логируются с типом `agent_response`
- [ ] Транскрипт клиента логируется с типом `user_transcript`

### Продажная логика
- [ ] Агент выявляет потребности (боли, цели, бюджет)
- [ ] Агент делает презентацию продукта по выявленным болям
- [ ] Агент отвечает на возражения
- [ ] Агент подводит к целевому действию (CTA)

### Завершение разговора
- [ ] Кнопка "Завершить разговор" останавливает микрофон
- [ ] WebSocket закрывается корректно
- [ ] Воспроизведение аудио останавливается
- [ ] UI возвращается в исходное состояние
- [ ] В логах появляется запись о завершении

### Обработка ошибок
- [ ] При отсутствии API-ключа показывается понятная подсказка
- [ ] При отказе в доступе к микрофону — ошибка в логах
- [ ] При разрыве WebSocket — сообщение об ошибке, UI не зависает
- [ ] Кнопки блокируются от повторного нажатия во время операций
